# IMDB Sentiment — Accuracy and Failure Modes

Repository for final prosjekt i ECE4450J Introduction to Machine Learning. Arbeidsoppgavene er som følger:

- **Eskil:** datapipeline, splitting og Naive Bayes, README og reproduserbarhet
- **Mads:** DistilBERT og E1 (accuracy per review-lengde)
- **Even:** E2 (kalibrering) og koordinering av feilanalysen

Alle er med på å håndmerke feil og skrive rapporten og presentasjonen.
